# Update-Bibliothek

Ordner `plugin-update-checker/` ist eine unveränderte Kopie des Plugin Update Checker, Release **v5.7** (Tag vom 2026-05-26), von https://github.com/YahnisElsts/plugin-update-checker (MIT-Lizenz, `license.txt` liegt bei).

Nicht kopiert: `examples/`, `build/`, `composer.json`, `phpcs.xml`, `.git`.

Ins Projekt kopieren nach `lib/plugin-update-checker/` im Plugin- oder Theme-Ordner. Der Ordner wird nicht von Hand verändert; neue Versionen werden komplett ersetzt.
